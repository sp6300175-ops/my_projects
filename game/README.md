# Game 🎮

A menu-based Python application that offers two fun mini-games using functions.

## Games Available

- **Rock Paper Scissors** – Classic hand game against the computer
- **Dice Roll** – Guess the number on the dice roll

## How to Run

```bash
python main.py
```

## Usage

When you run the program, a menu will appear:

```
1. Rock Paper Scissors
2. Dice Roll
3. Exit
```

- Enter **1** to play Rock Paper Scissors
- Enter **2** to play Dice Roll

## Game Descriptions

### 🪨 Rock Paper Scissors
Play the classic game against the computer. Choose Rock, Paper, or Scissors and see if you can beat the computer!

### 🎲 Dice Roll
Try to guess the number that appears on the dice roll. Test your luck!
