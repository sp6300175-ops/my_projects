# ATM Simulation 🏧

A menu-based Python application that simulates basic ATM operations using functions.

## Features

- **Display Balance** – View your current account balance
- **Deposit** – Add money to your account
- **Withdraw** – Withdraw money from your account
- **View Statement** – View your transaction history

## How to Run

```bash
python main.py
```

## Usage

When you run the program, a menu will appear:

```
1. Display Balance
2. Deposit
3. Withdraw
4. View Statement
5. Exit
```

Enter the number corresponding to the option you want and follow the prompts.

## Project Structure

